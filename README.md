# E-Hospital-Management-System
A Java-based E-Hospital Management System with Oracle Database integration.  Features include patient management, doctor scheduling, appointment booking, and billing. Developed using Java Swing, JDBC, and Oracle DB.
# 🏥 E-Hospital Management System

The *E-Hospital Management System* is a Java-based application designed to digitize and automate hospital operations. It provides a centralized platform for managing patients, doctors, appointments, and billing, making healthcare administration more efficient and reliable.

---

## 📌 Features
- *Patient Management*
  - Add new patients
  - Update patient details
  - View patient records
- *Doctor Management*
  - Manage doctor information and schedules
- *Appointment Scheduling*
  - Book appointments with doctors
  - Prevent scheduling conflicts
- *Billing Management*
  - Generate and store billing records
  - Track payment status with timestamps

---

## 🛠 Technologies Used
- *Java* – Application Development  
- *Java Swing* – Graphical User Interface (GUI)  
- *Oracle Database* – Data storage  
- *JDBC* – Database connectivity  

---

## ⚙ System Modules
1. *Login & Signup*
2. *Patient Dashboard*
3. *Doctor Management*
4. *Appointment Scheduling*
5. *Billing Management*
